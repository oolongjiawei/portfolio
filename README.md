# Dorie Long — Portfolio

Personal portfolio of Dorie (Jiawei) Long, Applied AI Solutions Developer in Toronto.

Plain HTML/CSS/JS, no build step. The hero features an interactive IK rig (FABRIK solver in `main.js`) — a nod to five years of character rigging for Looney Tunes.

**Live:** https://dorie-long.vercel.app

## Run locally

```bash
python3 -m http.server 8000
```
