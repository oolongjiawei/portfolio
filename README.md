# Dorie Long — Portfolio

Personal portfolio of Dorie (Jiawei) Long, front-end developer and data analyst in Toronto.

Plain HTML/CSS/JS, no build step. The hero features an interactive 2.5D character rig (`rig.js`: IK limbs with pole vectors, turnaround, depth sorting) — a nod to five years of character rigging for Looney Tunes.

**Live:** https://dorie-long.vercel.app

## Run locally

```bash
python3 -m http.server 8000
```
